# kasan-round-app（相互ラウンド）

感染対策向上加算１の相互ラウンド（別紙24・令和8年度「感染対策向上加算１チェック項目表」）をiPadで入力し、Excelに書き出すPWA。ホーム画面に追加して単独アプリのように使えます。

## 使い方

1. ホーム画面で評価実施日（既定は本日）と評価対象医療機関名を入れて「開始」
2. 左の大項目（A〜L）を選び、各項目を A／B／C／X で評価、必要に応じてコメントを入力（同じボタンをもう一度押すと解除）
   - 「未評価をすべてA」「すべてX（該当なし）」「中項目の未評価をA」で一括入力
   - 「未評価へ↓」で未評価の項目へ移動
   - B・Cでコメントが空の項目には「理由を記入」と表示（Excelには出ない）
3. 「基本情報」で評価実施医療機関名・評価責任者名を入力（次回から自動入力）
4. 「集計・B/C一覧」で大項目ごとの件数・A率とB/C項目を確認
5. 「Excel出力」→ 共有シート（AirDropなど）で送信。ファイル名は `相互ラウンド_YYYYMMDD_医療機関名.xlsx`
6. 一覧の「開く」でいつでも再編集・再出力できます

## 仕組み

- データは端末の IndexedDB にのみ保存（サーバーには送信しない）。入力のたびに自動保存
- Excelは `template.xlsx`（別紙24の原本レイアウト＋集計シート）に、JSZipで評価・コメントを書き込んで生成。集計シートの数式はExcelで開いたときに計算される
- `items.js` は `template.xlsx` から自動生成した項目一覧（`row` = テンプレートの行番号）。テンプレートを差し替えたら作り直すこと
- `service-worker.js` でオフライン動作。アプリ本体を更新したら `CACHE_NAME` の番号を上げる（v2 → v3 のように）
